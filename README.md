SupraTooler
SupraTooler is a small MacOS application in development that gives the user easy keyboard shortcuts to help make life easier. For example, for Mac users that use a differnent keyboard than the default boring magic keyboard, you may have experience with the function keys not working properly. This application makes it so that your life is easier with shortcuts like teleporting your mouse to the top nav bar to check the time or connect bluetooth, and other quality of life improvements. SupraTooler, keeping your eyes on the prize.

There is no UI for this app. To get the app to work, you must give it the following permisions in privacy settings:
- Device Control and Data Access
- Input Monitoring
- Screen Recording
Thanks for trying the project out.

List of Shortcuts, in development and applied:
- function 1 (f1) : cursor to the top to reveal time and battery.
- function 2 (f2) : cursor to the bototm to reveal app list.
- command + w: cursor to the top left of the screen to easily close apps.
- other functions are being thought of as we speak
